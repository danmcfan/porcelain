# 0004: Test footage lives outside git

Status: Accepted

## Context

Real band footage is large (4K HEVC, hundreds of MB) and personal. It cannot live in git, but its quirks (rotation flags, extra audio streams, mixed frame rates) are what break media code.

## Decision

Real footage is located via the environment variable `PORCELAIN_FOOTAGE_DIR` and never committed. Automated tests use tiny Fixtures generated by ffmpeg in `scripts/gen-fixtures.sh` that reproduce each quirk documented in `docs/footage.md`.

## Consequences

- Tests that need real footage skip when `PORCELAIN_FOOTAGE_DIR` is unset.
- A newly discovered real-footage quirk is fixed by adding a Fixture that reproduces it, then a test.
- Running the tests locally needs ffmpeg installed to generate Fixtures.
